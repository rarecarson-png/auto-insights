ASSIGNMENT 6 UPLOAD

1. Extract this ZIP.
2. Open https://github.com/rarecarson-png/auto-insights
3. Select Add file > Upload files.
4. Upload the extracted contents, including the assignment6_figures folder. Do not upload the ZIP itself.
5. Commit changes and wait for GitHub Pages to deploy.
6. Open and check this URL, then submit it:
https://rarecarson-png.github.io/auto-insights/assignment6.html

The included index.html adds Assignment 6 to the homepage from your saved project. This is an update package; keep all existing repository files.
