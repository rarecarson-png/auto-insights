01 / SOURCE & STRUCTURE

A vehicle table, not a sales ledger

Source and purpose

The dataset is Car Features and MSRP, hosted on Kaggle under the CooperUnion account. Its listed description identifies vehicle attributes for predicting price. This investigation uses the original data.csv supplied for the project.

Research question: How do vehicle specifications and brand relate to the field labeled MSRP?

The Kaggle Data Card states that the data was scraped from Edmunds and Twitter. Its metadata lists creatorName as Jeffrey Shih, version 1, and a last update of December 21, 2016. The listed license is Unknown. This is a platform update date, not a documented collection date. Sampling details and the construction of MSRP and Popularity are not explained sufficiently for stronger claims. Kaggle metadata.

File and table structure

  • One structured, comma-separated table with a header row.
  • 11,914 observations; the header is not counted.
  • 16 named fields per observation.
  • 1,475,504 bytes: 1.476 MB (decimal), approximately 1.407 MiB.
  • Quoted fields preserve commas inside Market Category.
  • No full dates or timestamps. Year is an integer model-year variable.

Rows describe recorded vehicle configurations. They do not represent individual transactions, drivers, or sales totals.

02 / VARIABLES & SCHEMA

What each column means

Records, fields, and keys

Each row is a record; each column is a field. The schema specifies field names, interpretations, and data types. No primary-key column is provided. Make, Model, and Year together are not unique: there are 9,461 repeated combinations beyond their first occurrences.

Even all 16 fields do not uniquely identify every row because exact duplicates exist. A generated row number could serve as a technical row identifier while retaining the source file and original order. It would not identify a unique real-world vehicle.

Target and features

Target: MSRP, a numerical price field.

Candidate features: the other 15 columns. Make, horsepower, model year, size, style, fuel type, transmission, drivetrain, and efficiency relate directly to the proposed research. Popularity requires a definition before use.

There are 8 numerical columns, including Year and the target, and 8 categorical columns. Year is the only temporal field. Market Category is multi-label and would require parsing for category-level analysis.

Distinct counts exclude blank fields but retain literal N/A and UNKNOWN labels. Market Category counts distinct full combinations, not individual tags. Nullable whole-number fields appear as float64 in this pandas import because blanks are represented as NaN.

04 / DATA QUALITY

Missing values and repeated records

Missingness convention

There are 108 blank cells across four variables. The percentage for each field uses all 11,914 rows as its denominator. These are cell counts, not a count of distinct incomplete records.

N/A and UNKNOWN are reported separately. If a parser treats N/A as missing, Market Category would have 3,742 missing entries. Explicit handling avoids silently changing the meaning of a source label.

Duplicate definitions

715 rows (6.00%) repeat an earlier row exactly across all 16 columns. 1,332 rows belong to duplicated groups, including their first occurrences. Removing only repeated copies would leave 11,199 rows.

No records were removed in this investigation. Repeated specifications could reflect omitted trim detail, so duplicates need context before deletion.

Flags require investigation, not automatic removal

MSRP has 996 values above $74,078.125. The maximum is $2,065,902 for a 2008 Bugatti Veyron 16.4. High-end vehicles may be legitimate extremes. There are also 1,036 records at exactly $2,000, a possible price floor or source convention that the IQR rule does not flag.

Highway MPG reaches 354 and city mpg reaches 137. These entries need source and fuel-type checks, including whether electric-vehicle values use equivalent-MPG units. Zero cylinders can be meaningful for electric vehicles. Older years flagged by IQR are valid years, not necessarily errors. Popularity is a source score whose construction remains unresolved.

08 / RESEARCH CONNECTION

From investigation to research methods

Dataset description

The project uses the Kaggle Car Features and MSRP dataset, supplied as a 1,475,504-byte CSV with 11,914 observations and 16 variables. The data contains 48 makes, 915 model names, and model years from 1990 through 2017. MSRP is the proposed numerical target; vehicle attributes form the candidate explanatory variables.

Research methods

The original file was imported with pandas, preserving literal N/A and UNKNOWN labels and treating only blank fields as missing. The investigation counted observations, fields, distinct values, missing entries, and exact duplicate rows. Numerical summaries and 1.5-IQR flags were calculated without deleting or imputing values.

A histogram, brand-count bar chart, size-grouped box plot, and horsepower-price scatter plot were produced with matplotlib. Only the scatter plot excluded records, specifically the 69 without horsepower. Preliminary Pearson correlation used raw horsepower and raw MSRP.

Preliminary findings and next steps

Recorded prices are right-skewed. Median price increases across the recorded size categories, and horsepower has a positive raw-scale association with price. These results support further investigation of the proposed hypotheses, but do not test adjusted brand effects or establish causality.

Before Assignment 3, verify the price field and its $2,000 floor, inspect efficiency units and zero-cylinder records by fuel type, investigate duplicates, and decide how blank fields and N/A labels should be handled. Preserve the original file and document every transformation. If predictive modeling follows, prevent related configurations or exact copies from leaking across training and test sets.

Reproduce the investigation

Download investigate.py and keep it next to data.csv. In Python with pandas, NumPy, and matplotlib installed, run:

python investigate.py data.csv

The script writes four PNG figures and a complete profile to analysis-output/. The website report embeds its charts, so viewing them requires no chart service or API key.

Versions used: Python 3.12.14, pandas 2.2.3, NumPy 2.3.5, matplotlib 3.10.8.
