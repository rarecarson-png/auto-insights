# Assignment 3 — Data Preparation / Methodology

The original Kaggle Car Features and MSRP dataset contained 11,914 records and 16 fields. The raw CSV was preserved, and each prepared record received a source_row_id corresponding to its original one-based data-record position. Exact duplicates were identified across all 16 original fields before any transformations; 715 repeated copies were removed while retaining the first occurrence. This produced 11,199 records. This is a record-level deduplication decision, not proof that repeated rows represent the same physical vehicle.

Column names were standardized to snake_case. Numerical fields were converted to nullable integers, while text categories were standardized without merging distinct makes, models, or drivetrain categories. Comma-separated market-category tags were lowercased, sorted, deduplicated within each record, and separated by pipes. Blank cells remained missing. The source labels N/A in Market Category and UNKNOWN in Transmission Type were treated as unspecified information and converted to missing values. No numerical or categorical values were imputed. This choice avoids inventing specifications, but available-case analyses may still be biased if missingness is systematic.

Positive-value and nonnegative-value checks were applied according to each field's meaning, and model years were screened against a broad 1886–2027 range fixed for this project. All nonblank numeric source tokens parsed successfully, and none failed those basic range checks. One non-electric vehicle's highway fuel-economy value of 354 exceeded the separate review threshold of 150 and was set to missing pending source verification. Its original value and source-row identifier were preserved in the change log. This is a conservative analysis rule rather than a verified correction. Electric-vehicle efficiency values were retained and flagged because their unit comparability requires verification.

Potential outliers in MSRP, horsepower, cylinders, and city and highway fuel economy were flagged using values strictly outside Q1 − 1.5 × IQR and Q3 + 1.5 × IQR, with linearly interpolated quartiles calculated after preparation on each field's nonmissing records. Flagged records were retained. Prices equal to the observed $2,000 source minimum were also flagged for review. A base-10 logarithm of positive MSRP was added alongside original prices to support analysis of the skewed price distribution. No winsorization, inflation adjustment, or causal interpretation was applied.

The prepared master table contains 35 columns: 16 renamed source fields and 19 provenance, transformation, missingness, review, and eligibility fields. There are 11,130 records with nonmissing make, model, year, horsepower, and MSRP for the defined core analysis, and 11,129 records in a conservative fuel-economy subset requiring a known non-electric fuel type and both efficiency values. These subsets overlap and are not universal complete-case samples. Future analyses must report their own inclusion rules. Validation confirmed row-count reconciliation, unique source-row identifiers, no duplicate prepared source-field combinations, nullable integer types, and a reversible logarithmic transformation. All cell edits and removed duplicate identifiers were exported for audit and reproducibility.
