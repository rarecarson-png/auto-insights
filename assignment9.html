Proposed Algorithm and Implementation

Read complete IEEE paperSource and resultsOpen reproduction notebook

Proposed workflow: family-aware log-price regression with fold-local preprocessing, training-only selection, and an error audit. This integrates existing methods; it is not a claim of a new tree algorithm.

Workflow

  1. Deduplicate the Kaggle CSV and define Make–Model families.
  2. Reserve an unseen-family holdout; fit preprocessing inside each training fold.
  3. Compare 16 fixed regression configurations using dollar MAE after inverse log transformation.
  4. Select Extra Trees by original three-fold CV MAE, then report test metrics.
  5. Compare global and per-make median baselines and inspect residuals, price groups, and partition sensitivity.

Prediction: MSRP = exp(f(x)) − 1. Numeric medians, missingness indicators, scaling, and one-hot encoding are learned from training data only.

Evidence and trade-offs

Extra Trees original test MAE: $5,575; RMSE: $13,431; R²: 0.922. MAE improves 58.1% over the per-make median. Random Forest has lower original test RMSE and XGBoost is slightly ahead on the added five-fold CV check, so no universal best-model claim is made.

Sixteen original models plus a supplemental XGBoost model exceed the 10-model A-level target. Configuration diversity and fair evaluation still matter. Future improvements include training-only tuning, external validation, feature ablations, and prediction intervals.
