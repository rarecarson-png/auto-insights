Two results worth distinguishing

Extra Trees wins validation. Random Forest wins this holdout.

Recommended candidate: Extra Trees

Lowest mean grouped validation MAE: $8,027. Random Forest scores $8,568, so Extra Trees is 6.3% lower on the selection metric. It combines randomized trees and captures nonlinear price relationships.

On the separate holdout: MAE $6,532, RMSE $15,363, R² 0.898. That is 66.9% lower MAE than the median-price baseline.

Best measured holdout: Random Forest

MAE $6,255, RMSE $13,539, R² 0.921. Its average miss is $277 smaller than Extra Trees on these records, and its lower RMSE indicates fewer or smaller large misses overall.

Both are promising. Extra Trees remains the validation-selected candidate; choosing Random Forest after seeing this holdout would require new evaluation data to make a clean final performance claim.

What this means: MAE is the average absolute dollar miss, not an error bound for each car. R² is a score relative to a mean-price reference, not “percent accuracy.” Neither result proves a universally best model.

Validation standard deviations: Extra Trees $786; Random Forest $560. These are variation across three folds, not confidence intervals or significance tests.

How this comparison was run

  1. Use all 11,199 cleaned records from Assignment 3. Predict recorded MSRP, not current sale prices.
  2. Keep the original seed-42 split: 8,875 training rows and 2,324 holdout rows, separated by make–model group. No group appears in both.
  3. Within the training set, run three-fold GroupKFold. Each fold fits its own median imputation, missing-value indicators, standardization, category imputation, and one-hot encoding.
  4. Fit fixed model configurations, then select the lowest unweighted mean validation MAE across the three folds. No hyperparameter search was performed.
  5. Refit each model on all training rows and report all holdout scores in dollars. The target is standardized within each fit and inverse-transformed for scoring. Predictions are not clipped.

Inputs: year, engine horsepower, engine cylinders, make, vehicle size, vehicle style, transmission, and driven wheels. The model name defines groups but is not a predictor. Price-derived features are excluded. Unseen categories are encoded as all-zero vectors; these predictions need caution.

Limits and next steps

The holdout was also used in the earlier three-model experiment, so it is not fresh final evaluation data. Repeated grouped validation and a new untouched evaluation set are still needed. Price-floor and extreme-price records remain included; sensitivity checks are future work. The data covers selected specifications from 1990–2017 and is not a random sample of transactions.

Small configuration or preprocessing changes can alter scores. The historical experiment is retained in the original comparison; this run uses dense encoded features and target standardization. A training score much better than validation can signal overfitting.
